# QuestionCard

The moment the last shared episode stops. The stage holds on the cliffhanger frame, dimmed (`uw-stage--dim`), and `uw-question` rises from the bottom with a label, the question in the character's own words, one line of context and a single primary button that opens the glimpses. On day 2 the same card shows the question with the button replaced by the audience result. You provide the question, the context line and the frame. Never show the two choices here: they are introduced by their glimpses.
