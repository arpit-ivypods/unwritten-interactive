# NavBar

Desktop: a single floating pill, centred, 60px tall, holding the wordmark, up to four destinations and one ink button (the audio language). The current destination is marked with `aria-current` and `brand-text`. Phone: `uw-nav--phone` keeps only the wordmark and one status chip at the top, and the destinations move to `uw-dock`, a floating pill at the bottom with an icon and label per destination (52px tall, current one filled ink). Below 640px the links hide on their own. Neither bar ever becomes a full-width strip.
