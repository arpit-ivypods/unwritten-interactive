# ShareCard

The 9:16 image a viewer saves after voting. Top: the wordmark in `on-stage`. Bottom, over `scrim`: series and episode, the question, a white pill with the viewer's letter and choice, and one line inviting a friend. It shows the cliffhanger frame, never a frame from either branch, and never the result. Export at 1080 x 1920; the preview is the same layout at a quarter scale. `uw-share-pick--b` for choice B.
