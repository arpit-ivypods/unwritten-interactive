# OtherEndingPanel

Two panels for day-1 viewers after an ending. The first offers the other branch: its verdict row, episode count, the closing countdown chip, a primary button and a quiet way out. The second appears only after both endings are finished: the viewer's current ballot, the live split, and two buttons of equal width, keep (ink) and move (glass). Moving is allowed once; say so. Neither panel is ever shown on day 2.
