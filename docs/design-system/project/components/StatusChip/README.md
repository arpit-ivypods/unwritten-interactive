# StatusChip

Small pills that say which day a story is in and what that means for the viewer. `uw-chip--live` for day 1 (both endings open), `uw-chip--alert` for the countdown in the final hours, `uw-chip--canon` for day 2 (only the official ending), `uw-chip--locked` for an expired ending, `uw-chip--plain` for neutral metadata. Colour is never the only signal: the words always state the state.
