# DemoDrawer

Presenter-only controls, opened by a long press on the wordmark and never shown to viewers. A glass drawer (`uw-drawer`) on the right edge with full-width segmented controls for the demo clock (day 1, last hour, day 2), the winning ending, the viewer state, and a reset button. Each group has a visible label tied to it with `aria-labelledby`. Changes apply immediately and only to the current device.
