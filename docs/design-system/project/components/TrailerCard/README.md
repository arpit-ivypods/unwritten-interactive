# TrailerCard

The pair of glimpses shown before the ballot, one per choice, always side by side so neither looks preferred. Each is a 9:13 card with a tag (A violet, B saffron), the choice as its title, and a meta line with its length and whether it has been watched. Watching them is optional: the viewer can vote straight away. On day 2 they are still offered so late viewers can see what they missed, but there is no ballot. Glimpses end on a new question; never use a frame that reveals the outcome as the card image.
