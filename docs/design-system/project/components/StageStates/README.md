# StageStates

What the stage shows when it is not playing. Loading: skeleton bars where the progress, title and subtitles will be, with a spinner and one line. Tap to play: the first frame under `uw-stage-state--veil` with the play control and a note that sound is on. Failed: a plain message and a retry button. Expired: the dimmed frame, a lock, why it is gone, and a button to the official ending. Every state says what happened and offers the next step; motion stops under reduced-motion.
