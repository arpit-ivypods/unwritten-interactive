# EpisodeRail

The episode path through a story. Shared episodes are numbered; the branch point is a saffron pill with the branch icon; episodes after it carry the branch letter (3A, 4A). `is-done` for watched, `is-now` for current, `is-locked` (dashed, lock icon) for the other ending until the viewer finishes their own. Each pill is at least 44px.
