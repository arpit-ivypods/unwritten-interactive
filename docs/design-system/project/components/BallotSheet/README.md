# BallotSheet

The phone ballot: a bottom sheet (`uw-glass uw-glass--sheet`) with a grabber, the label and countdown chip, the question as `uw-title`, the two BallotOption rows and one primary button whose label names the chosen letter. The button stays disabled until an option is selected and both glimpses are watched. On desktop the same contents sit in a compact glass panel to the right of the stage. Hindi text carries `lang="hi"` so it is never tracked.
