# Countdown

Time left in day 1, as three tabular-figure tiles (hours, minutes, seconds). Use it once per screen, on the home and series pages; inside sheets and panels use the `uw-chip--alert` chip instead. Add `uw-countdown--alert` in the last hour, which turns the figures to `alert`; the label above must also say so in words. Give the element `role="timer"` and an `aria-label` with the time in words, updated once a minute, not every second.
