# Logos

The mark is a path that forks in two inside a rounded square, with a saffron dot at the point of choice. Use `unwritten-mark.svg` (violet) on ground, veil and glass; use `unwritten-mark-mono.svg` (ink `#15131c`) where violet clashes with artwork. The wordmark is live text, not a file: "Unwritten" in Plus Jakarta Sans 800, letter-spacing -0.02em, followed by a full stop in `brand-text`. Minimum mark size 24px; keep clear space of a quarter of its width.
